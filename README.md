# 🌱 AI-Powered Crop Recommendation for Farmers

An AI-powered web application that recommends the most suitable crop based on soil nutrients and environmental conditions. The application provides secure user authentication, stores recommendation history in a MySQL database, and offers an easy-to-use interface for farmers.

---

## 📌 Features

- 👤 User Registration and Login
- 🔒 Secure Password Hashing using bcrypt
- 🌾 AI-Based Crop Recommendation
- 💾 Stores User Information in MySQL
- 📊 Saves Crop Recommendation History
- 📱 Responsive User Interface
- ⚡ Node.js & Express Backend
- 🗄️ MySQL Database Integration
